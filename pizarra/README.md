# Pizarra de Pronósticos · datos

Datos reales que alimentan la Pizarra de Pronósticos. El workflow `.github/workflows/pizarra-datos.yml` se ejecuta cada día y descarga de football-data.co.uk resultados, tiros, córners, tarjetas y cuotas (apertura y cierre) de 8 ligas, más los próximos partidos con cuotas. Todo se guarda en `pizarra/data/fd/`.

Esta carpeta es independiente del resto del repo.
